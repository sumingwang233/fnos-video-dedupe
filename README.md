# 视频查重助手 video-dedupe

简体中文 | [English](README.en.md)

扫描 NAS 授权目录里的视频，找出**字节完全相同**（SHA-256）与**画面高度相似**（pHash 视觉指纹）的重复文件，人工审阅后按签名计划执行**显式确认的永久删除**——删之前反复核对，删之后留档备查。

[下载](#下载) · [看看界面](#看看界面) · [三步开始](#三步开始) · [平时怎么用](#平时怎么用) · [常见问题](#数据与常见问题)

## 三步开始

1. **授权目录**：系统设置 → 应用 → 视频查重助手 → 访问权限，添加要扫描的文件夹。权限选**读写** ＝ 该目录中的重复视频可清理；选**只读** ＝ 仅作对比参考，绝不删除。
2. **扫描**：打开应用点「开始扫描」。首次会逐个读取视频画面计算指纹（大库可能需要数小时，建议停写后扫描）；之后重扫会自动跳过没有变化的文件，速度很快。
3. **审阅并清理**：逐组查看重复视频（缩略图 / 大小 / 距离），按建议勾选或手动调整 → 生成清理计划（自动预演，不会删除）→ 确认执行永久删除。删除明细自动存档到共享文件夹备查。

## 平时怎么用

| 想做的事 | 操作 |
|---|---|
| 新存了一批视频，想查重 | 概览 → 开始扫描 → 审阅 |
| 只扫某个子目录 | 概览 → 扫描范围 → 选择要扫描的子文件夹 |
| 同一部片子存了两份一模一样的 | 审阅页「完全重复」分组，按建议直接勾选 |
| 转码 / 压制产生的近似版本想留一个删一个 | 看「视觉相似」分组的缩略图与距离，手动挑选 |
| 查以前删过什么 | 共享文件夹 `video-dedupe/data` 里的删除记录（CSV / HTML） |
| 增删了授权目录或改了读写权限 | 系统设置改完后，停止并启动本应用；旧扫描作废重扫（指纹缓存保留，很快） |

## 数据与常见问题

**删除安全吗？会不会误删？**
按「默认预演」设计：没有显式确认绝不删除；每个重复组至少保留一份，全选会被拒绝；只读目录与硬链接永不进入删除名单。清理计划由内容哈希签名，执行时再次核对目录配置、挂载点、文件状态与 SHA-256，任何不符整批停止；Linux 上删除先在同目录原子暂存、复核后才真正移除，每一步先写 journal，中断可恢复。**但最终删除是永久的**（不进回收站），请在确认页看清楚再点。

**我的数据放在哪里？**
扫描数据库与缩略图在应用私有目录，不占用共享空间；删除明细（审计记录）导出到共享文件夹 `video-dedupe/data`，文件管理器随时可查。

**需要联网吗？要装 Python 或 Docker 吗？**
都不需要。v0.2.0 起为纯原生实现（无容器）；ffmpeg / ffprobe 与 numpy 全部随包内置，安装期零网络依赖。

**普通用户账号能操作吗？**
界面经飞牛统一网关接入，沿用 NAS 账号体系鉴权，仅管理员可进入与操作。

**和 v0.1.x 的 Docker 版是什么关系？**
v0.1.0 曾基于 VDF 容器实现，v0.2.0 起重写为纯原生 fpk 应用。两者数据不互通，建议卸载旧版换装新版。

**支持哪些视频格式？**
常见容器与编码由内置 ffmpeg 解码（mp4 / mkv / mov / avi / wmv / flv / m2ts 等）；损坏或无法读取的文件降级记录为警告，不会中断扫描。

__开发与项目结构__

Windows + WSL Ubuntu 双平台开发；Python 3.12 标准库为主（除 numpy 外零第三方 import），unittest 双平台全绿才可提交：

```sh
py -3.12 -X utf8 -m unittest discover -s tests -v        # Windows 测试
py -3.12 -X utf8 build_fpk.py                            # 构建 fpk（fnpack 1.2.3）
VD_ALLOW_NO_ADMIN=1 py -3.12 -X utf8 webui.py --config config.local.json --tcp 18099  # 本地 UI 冒烟
```

架构一句话：`videodedupe.py`（扫描 / 指纹 / 分组 / 计划 / 删除引擎）＋ `webui.py`（stdlib http.server 界面，AF_UNIX socket 接统一网关）＋ `fpk/`（fnOS 应用骨架与生命周期脚本）＋ `build_fpk.py`（打包）。开发纪律与模块边界见 [AGENTS.md](AGENTS.md)，验证记录见 [VALIDATION.md](VALIDATION.md)。
