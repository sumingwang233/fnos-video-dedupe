# 视频查重助手 v0.2.27

## 简体中文

本版本将 Web 界面全面对齐 Strata 设计语言：浅色主题成为默认、顶栏 + 居中单列布局、概览页仪表盘化，并为全站加入实时任务状态胶囊。删除安全引擎与既有操作流程零改动。

**正式发布，真机验收待完成。** 双平台单元测试（Windows / WSL Ubuntu 各 41 项）、fnpack 构建、本地 `--tcp` 冒烟全链路（扫描 → 审阅 → 计划 → 确认页）与双主题截图自查均已通过；fnOS 真机（1.2.0800，x86）装机验收尚未执行，装机组装请先以测试目录走完整流程再用于真实媒体库。

### 主要变化与修复

- 设计令牌整体迁移到 Strata 体系：浅色（#f9fafb 背景 / 白卡 / 翡翠绿 #10b981）为默认主题，`html.dark` 深色一键切换；深蓝旧皮肤退役。
- 布局从侧栏改为顶栏 + 居中单列：sticky 毛玻璃顶栏、胶囊分段导航（概览 / 审阅 / 设置），880px 以下自适应窄屏。
- 概览页仪表盘化：阶段进度链（扫描 → 生成计划 → 确认删除 → 清理完成）与四张指标卡（重复组 / 删除候选 / 可释放空间 / 视频总数），指标口径与审阅页预勾选完全一致。
- 全站实时状态胶囊：任何页面顶栏常驻显示扫描 / 计划 / 删除进度（自适应轮询间隔，切回标签页立即唤醒），点击回到概览。
- 自托管 Outfit 可变字体（woff2 随包内置，SIL OFL 1.1），安装与运行零外部网络请求；新增 `/font` 路由，缺字体文件时 404 降级不崩。
- 引擎 `videodedupe.py` 仅版本号变更；删除双确认、保护语义与安全文案逐字未动。

### 升级与数据保留

在应用中心直接安装本 fpk 覆盖升级。应用私有数据（扫描数据库、指纹缓存、缩略图）与共享目录中的审计记录全部保留；目录配置未变化时旧扫描结果继续可用，无需重扫。本次为界面重构，无数据结构迁移。版本逐条变更见 [Log.md](https://github.com/sumingwang233/fnos-video-dedupe/blob/main/Log.md)。

## English

This version realigns the web UI with the Strata design language: light theme becomes the default, the layout moves to a top bar with a centered single column, the overview page becomes a dashboard, and a live task-status pill is added across the app. The deletion-safety engine and existing workflows are untouched.

**Official release; on-device acceptance still pending.** Unit tests on both platforms (41 tests each on Windows / WSL Ubuntu), the fnpack build, and a full local `--tcp` smoke chain (scan → review → plan → confirmation) plus dual-theme screenshot review have all passed. Installation and acceptance on a real fnOS machine (1.2.0800, x86) has not been run yet — validate with a test folder before pointing it at a real library.

### Highlights and fixes

- Design tokens migrated to the Strata system: light theme (#f9fafb background / white cards / emerald #10b981) by default with one-click dark mode; the old dark-blue skin is retired.
- Sidebar replaced by a top bar + centered single column: sticky blurred header, pill-style segmented navigation, responsive below 880px.
- Dashboard-style overview: a stage chain (scan → plan → confirm → done) and four metric cards (duplicate groups / delete candidates / reclaimable space / total videos), using exactly the same criterion as the review page pre-selection.
- A live status pill on every page shows scan / plan / deletion progress (adaptive polling, immediate wake on tab visibility), linking back to the overview.
- Self-hosted Outfit variable font (woff2 bundled, SIL OFL 1.1) — zero external network requests at install or runtime; a new `/font` route degrades to 404 if the files are missing.
- The engine (`videodedupe.py`) only bumps its version constant; double-confirmation, protection semantics and safety copy are verbatim unchanged.

### Upgrade and data preservation

Install this fpk over the previous version in the App Center. App-private data (scan database, fingerprint cache, thumbnails) and audit records in the shared folder are all preserved; existing scan results remain usable when folder authorizations are unchanged — no rescan required. This is a UI rework with no data migration. Per-version changes are in [Log.md](https://github.com/sumingwang233/fnos-video-dedupe/blob/main/Log.md).
